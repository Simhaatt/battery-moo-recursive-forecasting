# Result artifacts

These are authoritative, derived experiment outputs used by the final manuscript. They are grouped into optimizer search, noise floor, ten-seed final evaluation, stress ablation, sequence/PINN baselines, grouped cross-validation, transfer, and audit results.

Files in `generated/` are recreated by `python analysis/reproduce_all.py`; source artifacts elsewhere in this directory are treated as immutable inputs. The reproduction command never overwrites the raw inputs.
